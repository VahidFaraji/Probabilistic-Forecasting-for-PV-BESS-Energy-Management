# Probabilistic-Forecasting-for-PV-BESS-Energy-Management


## Project Overview

This is an ongoing research project that builds on my previous work in electricity load forecasting and machine learning for energy systems.

The project extends forecasting from a prediction task toward its practical 
use in power systems. In particular, I am investigating how point and 
probabilistic forecasts can support the operation of residential PV–battery 
energy storage systems (PV–BESS) through optimization-based energy management.

The current work combines load and PV forecasting, battery modeling, and 
energy management optimization, with particular attention to the operational 
value of forecast uncertainty.

⚡ **Status:** Work in progress.

## Dataset

The project uses the Ausgrid Solar Home Electricity dataset, which contains
half-hourly residential electricity consumption and rooftop PV generation
data from 300 customers.

The current development and evaluation are performed on one customer while
the forecasting and EMS framework is being established. Extension to
additional customers is planned after the methodology is finalized.
